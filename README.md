# CodeJudge SQL Query Implementation

This repository contains SQL queries written for the CodeJudge database.

The queries include:
- Basic retrieval
- Filtering
- Joins
- Aggregation
- HAVING clause
- Subqueries
- Validation reasoning

All queries are written using standard SQL syntax and tested logically on the relational schema created in Part 1.

## Files Included

- queries.sql
- query_outputs.md
- sql_reasoning.md

The outputs and validation notes are included to explain why the query results are logically correct.
